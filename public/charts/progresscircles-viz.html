Progress Circles

Progress Circles for Data Studio, formerly known as Looker Studio.

A row of donuts that each say "X% done" — instantly readable.

Add to Data Studio → Open live demo
Cross-filter ready Theme-aware Setup in 30s

What it is

Progress Circles render a grid of circular gauges, one per category, each filled to a percentage with the value in the center. Perfect for OKR tracking and any tile-of-tiles goal layout.

What it does

N circular progress rings sized uniformly, each with label and configurable color thresholds.

Why use it

More visually interesting than a bar list when you have ≤12 items and want each to feel like a card.

Three ways teams use it

Strategy
Quarterly OKRs — one circle per KR.
Marketing
Campaign delivery progress per goal.
Learning
Training module completion per employee.

Add it in 30 seconds

  1. Open your Data Studio report and click Add a chart → Community visualizations → Explore more.
  2. Paste the Viz Studio manifest URL or pick this chart from the Viz Studio gallery card.
  3. Bind the dimensions and metrics in the data panel — done.
