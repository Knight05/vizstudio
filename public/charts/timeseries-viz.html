What it is

Time Series with Annotations is a clean line chart that lets you mark events on the timeline: launches, incidents, campaigns, holidays. The annotations are first-class, not a hack.

What it does

Single or multi-series line over time with vertical event annotations (label + color), tooltip, cross-filter.

Why use it

Spikes in a time series only mean something with context. Annotations put the context inline.

Three ways teams use it

Product
DAU line with launch annotations.
Marketing
Conversion line with campaign markers.
Ops
Latency with incident annotations.

Where your annotations come from

Annotations are just data, no hardcoding events into the chart. Blend your metrics with an events source and the markers appear on the timeline automatically.

Google Sheets
Keep a simple sheet of date + label + type and blend it with your metrics. Anyone on the team can add an event, the chart picks it up on the next refresh.
Google Calendar connector
Pull your sales calendar straight into Data Studio with our Google Calendar data connector: promos, launches, and key events land on the chart without maintaining a separate list.

Settings you can tune

Everything below lives in the chart's Setup and Style tabs in Data Studio. Colors default to your report theme: change any of them whenever you want.

Data setup

  • Date: one time dimension drives the X axis.
  • Metrics: up to 5 series, each with its own theme-mapped color.
  • Annotation Label (optional), the text shown at each event.
  • Annotation Type (optional), a keyword field that routes each event to one of the 10 icon/color type slots.

Line settings

  • Line width (1–8) and curve type: Linear, Smooth (Monotone), Step, Natural, or Basis.
  • Data points: toggle on/off, set radius (1–10).
  • Area fill: optional fill under each line with adjustable opacity.
  • Series 1–5 colors: default to the report theme palette, fully overridable.

Annotation settings

  • Placement: Top, Bottom, or directly On Line.
  • Multiple annotations per day: Stack Vertically, First Icon + Count, or Side by Side.
  • Icon size (12–40 px), marker line color and style (solid / dashed / dotted).
  • Labels: show/hide, auto-shorten long labels with a max character cap, optional count badge under the icon, font size and color.
  • Hover card: choose what appears on hover: icon, type, label.
  • Integration: show annotations inside the line tooltip, in the legend, and on comparison date ranges.

Annotation types (10 slots)

Each slot is a keyword + icon + color. When an event's Annotation Type value matches a keyword ("sale", "error", "launch"…), it gets that slot's icon and color. Ten slots, thirty icons, any color: enough to build your own event taxonomy.

Axis & grid

  • X/Y axis toggles and axis color.
  • Date format presets: Mar 9 · Mon, Mar 9 · 3/9 · Mar 9, 2024 · 2024-03-09, plus a free-form custom date pattern (e.g. MMM yyyy) under Date Format.
  • Grid lines: horizontal and vertical toggles, solid/dashed/dotted style, opacity, color.

General, tooltip & numbers

  • Font: family, size, color across the chart.
  • Legend: top, bottom, right, or none.
  • Null values: render as a gap, zero, or interpolate across.
  • Tooltip: toggle, background, border, font color/size, opacity.
  • Numbers: compact notation (1.2K, 3.4M) and decimal precision (auto or 0–3).

Add it in 30 seconds

  1. Open your Data Studio report and click Add a chart → Community visualizations → Explore more.
  2. Paste the Viz Studio manifest URL or pick this chart from the Viz Studio gallery card.
  3. Bind the dimensions and metrics in the data panel. Done.
