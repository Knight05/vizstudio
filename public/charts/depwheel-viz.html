Dependency Wheel

Dependency Wheel for Data Studio, formerly known as Looker Studio.

Dependency wheel, a chord diagram that shows what hangs on what.

Add to Data Studio → Open live demo
Cross-filter ready Theme-aware Setup in 30s

What it is

Dependency Wheel arranges entities around a ring and draws directed arcs showing dependency strength. Hover one node to see exactly what it depends on (and what depends on it).

What it does

Circular node layout with directed dependency arcs, hover-highlight an ego dependency network, optional tick marks and group palettes.

Why use it

Software, supply chains, and org topologies all have implicit dependency graphs. This makes them visible.

Three ways teams use it

Engineering
Service-to-service dependency map.
Ops
Supplier dependency for a critical SKU.
Compliance
Process dependencies for a control audit.

Add it in 30 seconds

  1. Open your Data Studio report and click Add a chart → Community visualizations → Explore more.
  2. Paste the Viz Studio manifest URL or pick this chart from the Viz Studio gallery card.
  3. Bind the dimensions and metrics in the data panel. Done.
